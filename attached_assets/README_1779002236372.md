# Cambridge 9709 AI Tutor — Full RAG Stack

Elite Cambridge A-Level Mathematics tutor powered by **Claude AI + RAG** (Retrieval-Augmented Generation) with official Cambridge documents.

## Architecture

```
Cambridge PDFs → pdf-parse → chunker → OpenAI embeddings → Pinecone
                                                                ↓
Student query → embed query → cosine search → top-5 chunks
                                                    ↓
                              Claude (with Cambridge context injected)
                                                    ↓
                              Streaming response + source citations
```

## Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 14 (App Router) |
| AI | Claude claude-sonnet-4-20250514 (Anthropic) |
| Embeddings | text-embedding-3-small (OpenAI) |
| Vector DB | Pinecone (serverless, free tier) |
| PDF parsing | pdf-parse |
| Streaming | Server-Sent Events (SSE) |
| Deploy | Vercel (recommended) |

## Setup — Step by Step

### 1. Clone & install

```bash
git clone https://github.com/YOUR_USERNAME/cambridge-9709-rag
cd cambridge-9709-rag
npm install
```

### 2. Get your API keys

| Service | URL | Free tier |
|---------|-----|-----------|
| Anthropic (Claude) | https://console.anthropic.com | Yes |
| OpenAI (embeddings) | https://platform.openai.com/api-keys | $5 credit |
| Pinecone (vector DB) | https://app.pinecone.io | 1 free index, 100k vectors |

### 3. Configure environment

```bash
cp .env.example .env.local
```

Edit `.env.local` and fill in all keys.

### 4. Download Cambridge documents

Go to: https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-international-as-and-a-level-mathematics-9709/

Download and organise into:
```
cambridge-docs/
  syllabus/
    9709_syllabus_2025-2027.pdf
  past-papers/
    9709_s22_qp_11.pdf
    9709_s22_qp_12.pdf
    9709_w22_qp_11.pdf
    ... (2019-2024)
  mark-schemes/
    9709_s22_ms_11.pdf
    9709_s22_ms_12.pdf
    ...
  specimen/
    9709_specimen_qp_1.pdf
    9709_specimen_ms_1.pdf
```

**File naming convention** (Cambridge's standard format):
- `9709` = subject code
- `s` = May/June, `w` = Oct/Nov, `m` = Feb/Mar
- `22` = year (2022)
- `qp` = question paper, `ms` = mark scheme
- `11` = paper number

### 5. Create Pinecone index

The ingestion script creates the index automatically. Or create manually:
- Name: `cambridge-9709`
- Dimensions: `1536`
- Metric: `cosine`
- Cloud: AWS us-east-1 (free serverless)

### 6. Run ingestion

```bash
npm run ingest
```

This will:
1. Walk all PDFs in `cambridge-docs/`
2. Extract text (pdf-parse)
3. Chunk into ~500 token segments
4. Embed each chunk (OpenAI text-embedding-3-small)
5. Upsert into Pinecone with metadata

**Expected time:** ~5-15 minutes for a full set of past papers (2019-2024).
**Expected vectors:** ~15,000-40,000 depending on how many papers.

Or use the admin web UI at `/admin` (see below).

### 7. Start development server

```bash
npm run dev
```

Open http://localhost:3000

## Adding new documents (ongoing)

### Option A — CLI (fastest)

Add PDF to `cambridge-docs/`, then:
```bash
npm run ingest
```

The script is idempotent — it overwrites vectors with the same ID, so safe to re-run.

### Option B — Admin web UI

Go to http://localhost:3000/admin

Enter your `ADMIN_SECRET`, drag-and-drop PDFs, click Ingest.
Works for teachers who don't have terminal access.

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

Add all environment variables in the Vercel dashboard:
- `ANTHROPIC_API_KEY`
- `OPENAI_API_KEY`
- `PINECONE_API_KEY`
- `PINECONE_INDEX_NAME`
- `ADMIN_SECRET`

The `/admin` route is protected by `ADMIN_SECRET` — never expose this to students.

## API Routes

| Route | Method | Description |
|-------|--------|-------------|
| `/api/chat` | POST | Streaming chat with RAG context |
| `/api/exam` | POST | Generate Cambridge-style exam questions |
| `/api/ingest` | POST | Upload PDFs (admin, requires secret header) |

### `/api/chat` request body
```json
{
  "messages": [{ "role": "user", "content": "Solve: ..." }],
  "topic": "Pure 1",
  "useRAG": true
}
```

### `/api/exam` request body
```json
{
  "topics": ["Integration", "Differentiation"],
  "numQuestions": 5,
  "difficulty": "mixed"
}
```

### `/api/ingest` (admin)
```
POST /api/ingest
Header: x-admin-secret: YOUR_ADMIN_SECRET
Body: multipart/form-data with files[]
```

## How RAG improves quality

Without RAG (base Claude):
> "The mark scheme awards M1 for correct integration method..."

With RAG (Cambridge documents in context):
> "According to the **2022 May/June Mark Scheme Paper 11**, M1 is awarded for attempting integration by parts with u = x and dv/dx = e^(2x). The exact wording is: 'M1 — for valid attempt at integration by parts with u and dv correctly identified.'"

The difference is specificity — real mark scheme wording, actual paper references, exact Cambridge expectations.
